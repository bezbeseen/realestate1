📚 Image Management Guide

BE SEEN - Complete Guide to Image Management System

🎯 System Overview

This enhanced image management system allows you to:

  • Manage 43+ website images and 100+ review images
  • Edit alt text for accessibility and SEO
  • Add variable names for template integration
  • Use cloud URLs or local paths
  • Export JSON for development use

📝 Image Structure

Each image now has this enhanced structure:

{ "path": "/assets/images/logo/BeSeen_1.png", "alt": "BeSeen Logo - Professional Printing Services", "variable": "LOGO_MAIN" }
  • path: Image URL or file path (supports cloud URLs)
  • alt: Alt text for accessibility and SEO
  • variable: Variable name for template use (optional)

🔧 How to Use

📝 Adding New Images
  1. Click "Add Image" button on any category
  2. Select the target category
  3. Enter image name (e.g., "heroBanner")
  4. Enter image path/URL (supports cloud URLs)
  5. Enter descriptive alt text
  6. Add variable name (optional, e.g., "HERO_BANNER")
  7. Click "Add Image" to save
✏️ Editing Images
  1. Hover over any image to see edit button
  2. Click "Edit" to open the edit modal
  3. Update path, alt text, or variable name
  4. Click "Save Changes" to update
🗑️ Deleting Images
  1. Hover over any image to see delete button
  2. Click "Delete" to remove the image
  3. Confirm deletion in the popup
💾 Exporting Data
  1. Click "Save Changes" to download JSON file
  2. Click "Export JSON" to copy to clipboard
  3. Use the JSON in your templates or code

☁️ Cloud Hosting Support

You can easily switch from local paths to cloud URLs:

// Local path (current) "path": "/assets/images/logo/BeSeen_1.png" // Cloud URL (future) "path": "https://your-cloud-storage.com/images/logo/BeSeen_1.png"

Benefits:

  • Easy migration to cloud hosting
  • Better performance with CDN
  • Reduced server load
  • Scalable image delivery

🔤 Variable Names for Templates

Add variable names to easily use images in your code:

// In your image library "main": { "path": "/assets/images/logo/BeSeen_1.png", "alt": "BeSeen Logo", "variable": "LOGO_MAIN" } // In your templates/code const logoPath = IMAGE_LIBRARY.website.logo.main.path; const logoAlt = IMAGE_LIBRARY.website.logo.main.alt;
