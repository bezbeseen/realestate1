📋 Template Usage Examples

Breadcrumb Section:
<section class="breadcrumb_section d-flex align-items-center clearfix" style="background-image: url({{getProductImage product_id}})"> <div class="container"> <div class="row"> <div class="col-12"> <h1 class="page_title mb-0">{{product_name}}</h1> <p class="mb-0 subtitle-text text-white">{{seo_description}}</p> </div> </div> </div> </section>
Product Gallery:
<div class="tab-content" id="productTabContent"> {{#each gallery.main_images}} <div id="{{id}}" class="tab-pane {{#if @first}}active{{else}}fade{{/if}}"> <img src="{{getProductImage product_id}}" alt="{{alt}}"> </div> {{/each}} </div>
Product Details:
<div class="details_content product-container" data-product-id="{{id}}" data-product-name="{{product_name}}" data-product-price="{{product_details.price}}" data-product-image="{{getProductImage product_id}}"> <h2 class="item_title mb_15">{{product_details.title}}</h2> <span class="price_text mb_30"><strong>${{product_details.price}}</strong></span> </div>

✅ Benefits of Template Changes

  • Centralized Management: All product images managed through variables
  • Consistent Naming: Uses the new CATEGORY_PRODUCT_VARIANT system
  • Easy Updates: Change image paths in one place (image library)
  • Type Safety: Variables ensure correct image references
  • Future-Proof: Easy to switch to cloud hosting later
