## 📱 USER CLASSIFICATIONS

**What Each Type Means:**
- **`new_visitor`** - First time on your site
- **`returning_visitor`** - Been here before, showing interest
- **`qualified_lead`** - Submitted contact form with email/phone
- **`hot_lead`** - Multiple visits + submitted form (PRIORITY!)
- **`engaged_visitor`** - 5+ visits, high interest

**Journey Stages:**
- **`awareness`** - Just discovered you
- **`consideration`** - Browsing, comparing options
- **`evaluation`** - Serious about purchasing  
- **`decision`** - Ready to buy (focus on these!)

## 🛠️ QUICK FIXES

### **If Analytics Stop Working:**
1. Check console for errors: F12 → Console
2. Look for: `✅ FRESH GA4 LOADED: G-1TBFCB5V4P`
3. Purge server cache if needed
4. Hard refresh browser (Cmd+Shift+R)

### **If Events Missing:**
1. Navigate to different pages
2. Click various CTAs to test
3. Check GA4 Realtime (not just DebugView)
4. Verify in incognito mode
